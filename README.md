# Catakig X

Support and privacy pages for **Catakig X**, a retro 8-bit computer emulator for the Mac.

The website lives in [`docs/`](docs/) and is published with GitHub Pages:

- Support: https://catakigx.github.io/Catakig-X/
- Privacy Policy: https://catakigx.github.io/Catakig-X/privacy.html

The FAQ on the support page is adapted from the app's Help › Troubleshooting & FAQ panel.
