Beta Testing

Help test Catakig X before it reaches the Mac App Store.

Catakig X is in public beta through Apple's TestFlight. Beta testers get pre-release builds for free, straight from Apple, and their reports shape what ships. Thank you for helping!

Join the Catakig X beta

What you need

  • A Mac with Apple silicon or an Intel processor, running macOS 14 (Sonoma) or later.
  • Apple's free TestFlight app from the Mac App Store.
  • An Apple Account, the one you use for the App Store.

How to join

  1. Install TestFlight from the Mac App Store.
  2. Click Join the Catakig X beta above. Your browser hands the link to TestFlight; if it doesn't, open TestFlight and use Redeem.
  3. In TestFlight, click Accept, then Install. Catakig X goes into your Applications folder like any other app.
  4. When a new build is ready, TestFlight lets you know and updates the app. Each build works for 90 days.

Places in the beta can be limited. If the link says the beta is full or not accepting testers, please try again later.

Getting started

The Help menu has a one-page Quick Start and the full User Guide. Your first Apple II starts with a built-in demonstration disk, and the ][+ and //e run on Catakig firmware with no ROM files at all. Apple's ROMs are not included, as in the release.

What to test

  • Your own disk images: booting, loading and saving (DSK, DO, PO, NIB, 2IMG, WOZ, and ZIP or GZ files).
  • Programs on Catakig firmware, compared with Apple's ROM if you have it. Programs that work on one and not the other are especially useful to hear about.
  • Games with joysticks, the keyboard joystick and game controllers; the mouse card; the Mockingboard; the clock card under ProDOS.
  • Display filters and full screen on your own displays; printing to PDF; saving and restoring machine states.
  • Anything in the FAQ or the guides that's wrong or unclear.

Sending feedback

  • Bug reports: while the problem is on the screen, choose Help › Save Bug Report…, which saves the Apple II's state, a picture of the screen and recent errors in one .zip file, and never sends anything by itself. Email it to catakigx@icloud.com with a sentence on what happened and what you expected.
  • Quick notes and screenshots: open TestFlight, select Catakig X and click Send Beta Feedback.
  • Crashes: if macOS offers to send a crash report after Catakig X quits unexpectedly, sending it through TestFlight helps too.

Please mention the build number (from About Catakig X), your Mac model and your macOS version, and don't send ROM files.

Privacy

Catakig X itself collects nothing, in the beta as in the release (see the Privacy Policy). TestFlight is Apple's service: Apple shares with the developer the crash reports and feedback you choose to send, and some basic tester information, under Apple's TestFlight terms.

Leaving the beta

In TestFlight, select Catakig X and click Stop Testing. When Catakig X is released, install it from the Mac App Store; your preferences, imported ROMs and saved state carry over, because both use the same sandbox folder.
